Contrat de location

De la soumission jusqu’au contrat signé en ligne, rangé dans le dossier du client et livré. Tout se fait depuis le Pilotage > Locations : Jose choisit le client, le type de contrat et les machines ; Odoo remplit le contrat Monroy original ; le client complète et signe en ligne.

Au bureau · Jose

1. Préparer le contrat

A1

Ouvrir un nouveau contrat

Pilotage > Locations > Nouveau contrat de location. Le même menu donne les contrats en cours, les tickets de reprise, la planification d’un ramassage et les types de contrat.

Le menu Locations du Pilotage

A2

Les types de contrat

Pilotage > Locations > Types de contrat. Chaque type porte ses règles : forfait annuel par machine, ce qui est couvert, frais d’appel inutile, taux horaire, clause pénale. Le texte du contrat imprimé dépend du type.

Chez vous : {{types_contrat}}.

Types de contrat (exemple de démonstration)

A3

Remplir le contrat

Client : tapez son nom ou son code client (ex. {{code}} pour {{commerce}}). Choisissez toujours le commerce (l’adresse où la machine sera installée), pas la bannière.

Type de contrat, Saison, prix de détail, puis les machines dans « Lignes de commande ».

Automatique : la Période de location est déjà proposée (aujourd’hui → dans un an) et le forfait annuel s’ajoute tout seul selon le type de contrat.

Nouveau contrat : période proposée sur un an (exemple de démonstration)

A4

Le contrat prêt à envoyer

Vérifiez le client, la période (début → fin) et les lignes : la machine et le forfait annuel d’entretien.

Contrat prêt (exemple de démonstration)

A5

Ce que le client remplira

Onglet Contrat (client) : initiales, signature au nom d’une compagnie, caution et propriétaire de l’immeuble. C’est le client qui les remplit en ligne ; vous pouvez les corriger ici.

Onglet Contrat (client) (exemple de démonstration)

A6

Envoyer au client

Bouton Envoyer : le courriel « Votre contrat de location à signer » part avec le bouton Lire et signer mon contrat et la soumission en PDF.

Le client doit avoir une adresse courriel sur sa fiche ; sinon Odoo la demande avant l’envoi.

Le courriel envoyé au client (exemple de démonstration)

Chez le client

2. Le client complète et signe

B1

Sa page

Le client clique sur le bouton du courriel : il voit la soumission et, dessous, le contrat Monroy complet.

La page du client (exemple de démonstration)

B2

Il remplit les cases bleues

Initiales, compagnie (oui / non), caution, propriétaire de l’immeuble. Tout s’enregistre seul pendant qu’il écrit.

Les cases à remplir dans le contrat (exemple de démonstration)

B3

Accepter et signer

Bouton Accepter et signer : il tape son nom et signe (automatique, dessin ou image).

La signature en ligne (exemple de démonstration)

B4

C’est confirmé

Le client voit « Votre commande a été confirmée » et peut télécharger sa copie.

Confirmation chez le client (exemple de démonstration)

B5

Le contrat signé

Sa signature, la date et les informations de caution sont dans le contrat.

Le contrat signé (exemple de démonstration)

Rien à faire

3. Ce qu’Odoo fait tout seul

C1

Le contrat est confirmé

Dès la signature : le contrat passe en Bon de vente, la livraison est créée, le PDF signé est dans le fil du contrat.

Contrat confirmé après la signature (exemple de démonstration)

C2

Rangé dans la fiche du client

Le contrat devient le contrat de location actuel du client, et le PDF signé est rangé dans ses Documents.

Fiche du client : contrat actuel (exemple de démonstration)

C3

Une carte verte pour Jose

Tableau de bord : Contrats signés ce mois, bouton Voir pour la liste.

Tableau de bord : contrats signés ce mois (exemple de démonstration)

Le jour de la livraison

4. Livrer la machine

D1

Le bon de livraison

Ouvrez la livraison depuis le contrat (bouton Livraison). Avant de valider : le technicien assigné (obligatoire), le n° de série de la machine, le prochain entretien et la fréquence.

Le bon de livraison (exemple de démonstration)

D2

Valider

Bouton Valider, puis Oui, valider : la machine passe « chez le client » et le stock est mis à jour. Une livraison validée ne se modifie plus.

La confirmation avant de valider (exemple de démonstration)

Fin du contrat

5. Reprendre la machine

E1

Les tickets de reprise

Automatique : 30 jours avant la fin d’un contrat, un ticket de reprise est créé avec les machines à récupérer, et Jose reçoit une activité.

Pilotage > Locations > Tickets de reprise, puis Planifier un ramassage.

Les tickets de reprise (exemple de démonstration)

Aide-mémoire

  1. Pilotage > Locations > Nouveau contrat de location.
  2. Client = le commerce (code client), type de contrat, saison, machines. La période d’un an est déjà proposée.
  3. Envoyer : le client remplit et signe en ligne.
  4. Signé : confirmé, livraison créée, PDF rangé, carte verte au tableau de bord.
  5. Livraison : technicien, n° de série, prochain entretien, puis Valider.
  6. Fin de contrat : ticket de reprise automatique 30 jours avant.
  7. Exemple chez vous : le contrat {{contrat}} de {{contrat_client}}.
