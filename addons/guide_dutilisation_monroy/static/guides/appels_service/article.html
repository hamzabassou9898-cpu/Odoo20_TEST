Appels de service

Le client appelle Jose ; Jose ouvre un ticket et choisit son type. Le type décide de la suite : une réparation ou un entretien part dans la journée d’un technicien, un ramassage crée le bon de retour, une machine à remplacer s’échange en une seule opération, un ajustement ouvre le contrat.

Au téléphone · Jose

1. Ouvrir le ticket

A1

La liste des appels

Pilotage > Appels de service : les tickets ouverts, regroupés par type. Cliquez sur un groupe pour voir ses tickets (client, machine, date prévue, technicien, planification).

Appels de service ouverts, groupés par type (exemple de démonstration)

A2

Nouveau ticket

Bouton Nouveau. Écrivez le sujet (ce que dit le client), puis le code client (ex. {{code}} pour {{commerce}}) : le client, son adresse, son contrat et ses machines se remplissent seuls.

Le code client et le type de ticket sont obligatoires.

Nouveau ticket (exemple de démonstration)

A3

Choisir le type de ticket

Réparation, Ramassage, Entretien, Machine à remplacer ou Ajuster un contrat. Chaque type est expliqué plus bas.

Les 5 types de ticket (exemple de démonstration)

Type 1

2. Réparation

R1

Remplir la réparation

Cochez le type de réparation (Coule, Ne gèle pas, Ne tourne pas, Fait du bruit, Gèle trop, Autre). Choisissez la machine (numéro de série) parmi celles du client, la date prévue et le technicien dans Assigné à.

Automatique : à l’enregistrement, l’intervention est créée (Planifié) et la tâche apparaît dans la journée du technicien et dans le Planning. Le bandeau vert ou orange dit ce que couvre le contrat du client et ce qui se facture.

Ticket de réparation planifié (exemple de démonstration)

R2

Le dossier du client et de la machine

Plus bas : la bannière, le parc de machines, la machine choisie (modèle, emplacement, dernier entretien) et les onglets Historique d’intervention, Historique de la machine, Appels de service et Machines chez le client.

Parc machines et historiques (exemple de démonstration)

R3

Terminer

Le technicien termine sur son téléphone (voir le guide Portail technicien) : le client signe, le bon signé arrive dans le ticket. Au bureau, le bouton Marquer comme fait fait la même chose sans le téléphone : l’intervention passe « Faite » et le ticket « Résolu ».

Puis Facturer les frais : bon de vente des frais (main-d’œuvre, déplacement, pièces) selon le contrat.

Type 2

3. Entretien

E1

Le ticket d’entretien arrive tout seul

Automatique : un mois avant l’échéance, Odoo crée un ticket Entretien pour chaque machine chez un client (bandeau bleu « créé automatiquement »), avec les étiquettes « en retard » ou « à faire cette semaine ».

Jose indique le technicien (Assigné à) et la date prévue : l’entretien est planifié.

Ticket d’entretien créé par Odoo (exemple de démonstration)

E2

Valider l’entretien

Marquer comme fait ouvre la validation : date de l’entretien, fréquence (ex. tous les 12 mois), technicien et ce qui a été fait.

Automatique : le prochain entretien de la machine est recalculé selon la fréquence.

Valider l’entretien (exemple de démonstration)

Type 3

4. Ramassage

M1

Le ticket de ramassage

Automatique : 30 jours avant la fin d’un contrat de location, Odoo crée le ticket de reprise avec les machines à reprendre. Vous pouvez aussi créer un ticket « Ramassage » à la main : Odoo cherche les machines louées chez le client.

Ticket de reprise en fin de location (exemple de démonstration)

M2

Créer le bon de ramassage

Bouton Ramassage : un seul bon de retour pour toutes les machines du contrat, avec leur numéro de série. Choisissez le technicien assigné : il est obligatoire pour valider le ramassage.

Sur son téléphone, le technicien coche l’état des équipements (Très propre, Moyen, Sale, Pleine, En fonction) et le client signe.

Bon de ramassage créé depuis le ticket (exemple de démonstration)

Type 4

5. Machine à remplacer

X1

Choisir la machine de remplacement

Le client doit avoir au moins une machine chez lui. Choisissez sa machine actuelle puis la machine de remplacement (en entrepôt, même modèle).

Ticket « Machine à remplacer » (exemple de démonstration)

X2

Échanger en une seule opération

Bouton Échanger la machine : Odoo crée le ramassage de l’ancienne machine et la livraison de la nouvelle, validés ensemble. L’inventaire suit tout seul : l’ancienne revient en entrepôt, la nouvelle est chez le client.

Machine actuelle et machine de remplacement (exemple de démonstration)

Type 5

6. Ajuster un contrat

C1

Le ticket d’ajustement

Le client veut changer son contrat (ajouter une machine, changer de saison…). Bouton Ajuster le contrat.

Ticket « Ajuster un contrat » (exemple de démonstration)

C2

Le contrat s’ouvre

Le contrat de location du client s’ouvre : modifiez les lignes ou la période, puis envoyez-le de nouveau au client si besoin (voir le guide Contrat de location).

Le contrat du client, prêt à ajuster (exemple de démonstration)

Aide-mémoire

  1. Pilotage > Appels de service > Nouveau : sujet, code client, type de ticket.
  2. Réparation : type de réparation, machine, date, technicien → planifié tout seul.
  3. Entretien : créé par Odoo un mois avant ; ajoutez technicien et date ; Marquer comme fait recalcule le prochain.
  4. Ramassage : bouton Ramassage → bon de retour ; technicien obligatoire.
  5. Machine à remplacer : machine de remplacement, puis Échanger la machine.
  6. Ajuster un contrat : bouton Ajuster le contrat.
  7. Travail fait : Facturer les frais si le contrat ne les couvre pas.
